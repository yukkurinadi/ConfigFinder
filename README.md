# YMM4 設定検索プラグイン(YMM4ConfigFinder)

ゆっくりMovieMaker4で、この設定どこだっけというとき検索することで見つかります(ただしたまえがわかっている必要あり)

---
## 制作者

▶▶制作者:[ゆっくりなぢ](https://x.com/yukkurinadi)

---
## 主な機能・特徴
1. YMM4の設定は豊富なのでおすすめ設定などで調べてもどこにあるかわからない、見つけるのめんどくさい
そういうときに使えます。
2. 使用方法はYMM4標準の設定から使えます。　設定の上部に検索ボックスが追加されています。そこに入力したら検索できます。
3. 検索結果表示方法を変えられます。設定→その他に設定検索があると思います。そこから検索結果をハイライトするか検索結果のみ表示するか選べます。

---
## インストール方法
GithubリポジトリのReleaseから最新版の.ymmeファイルをダウンロードして実行すると自動的にインストールされます。
